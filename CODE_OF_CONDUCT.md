
# Código de Conduta

## Nosso compromisso

Como pessoas que contribuem para o Zest, queremos que a participação seja uma experiência livre de assédio para todo mundo, independentemente de idade, corpo, deficiência visível ou invisível, etnia, características sexuais, identidade e expressão de gênero, nível de experiência, formação, classe social, nacionalidade, aparência, raça, religião (ou falta dela), origem socioeconômica ou orientação sexual.

O Zest é um projeto sobre terminal e documentação em português. Discussão técnica dura é bem-vinda; ataque pessoal não.

## Padrões esperados

Exemplos de comportamento que contribuem para um ambiente saudável:

- Usar linguagem acolhedora e inclusiva
- Respeitar pontos de vista e experiências diferentes — muita gente chegou no Linux por caminhos diferentes
- Dar e aceitar críticas técnicas com bom senso
- Focar no que é melhor para o projeto e para quem usa
- Ser empático com quem está aprendendo shell

Exemplos de comportamento inaceitável:

- Uso de linguagem ou imagens de cunho sexual, e avanços sexuais de qualquer tipo
- Comentários ofensivos, ataques pessoais ou políticos, e provocações
- Assédio público ou privado
- Publicar informações privadas de outras pessoas sem autorização explícita — isso inclui expor email, token ou `.zshrc` de alguém em issue
- Qualquer outra conduta que possa razoavelmente ser considerada inadequada em um ambiente profissional

## Responsabilidades

Quem mantém o projeto é responsável por esclarecer os padrões de comportamento aceitável e deve tomar medidas corretivas justas e adequadas diante de qualquer caso de comportamento inaceitável, incluindo remover, editar ou rejeitar comentários, commits, código e edições de wiki que não estejam alinhados a este código, além de banir temporária ou permanentemente contribuidores por outros comportamentos que considerar inapropriados, ameaçadores, ofensivos ou prejudiciais.

## Escopo

Este código de conduta se aplica a todos os espaços do projeto — issues, pull requests, discussões, commits e qualquer comunicação pública feita em nome do Zest. Também se aplica a espaços públicos quando uma pessoa representa o projeto ou suas comunidades.

## Como reportar

Casos de abuso, assédio ou comportamento inaceitável devem ser reportados abrindo uma issue no repositório ou, quando o caso envolver quem mantém o projeto, por canal privado: denúncia de segurança pelo [formulário de Security advisory](https://github.com/reginaldosevero/zest/security/advisories/new) (conversa privada) ou pelo canal privado listado no [SECURITY.md](SECURITY.md). Toda reclamação será lida e investigada com empenho e de forma justa.

A equipe do projeto tem o direito e o dever de manter sigilo sobre a pessoa que reporta, assim como a de qualquer pessoa acusada.

## Como quem mantém o projeto responde

Se uma pessoa violar este código de conduta, quem mantém o projeto pode seguir estas etapas, respeitando o que for necessário e adequado para a situação:

1. **Advertência privada** — um aviso sobre a conduta, sem expor ninguém publicamente.
2. **Advertência pública** — explicação pública de como a conduta afetou outras pessoas.
3. **Suspensão temporária** — sem interação por um período determinado, incluindo comunicação com quem mantém o projeto.
4. **Banimento permanente** — remoção de toda a participação no projeto.

## Atribuição

Este código de conduta é uma adaptação do [Contributor Covenant](https://www.contributor-covenant.org), versão 2.0, disponível em https://www.contributor-covenant.org/version/2/0/code_of_conduct.html.
